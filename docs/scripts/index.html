downloads-toolkit

three python scripts that clean up a messy Downloads folder. every move is logged and can be undone. none of them delete anything.

organize_downloads.py

sorts loose files into folders by type. leaves project files like package.json and Dockerfile alone.

python organize_downloads.py          # preview
python organize_downloads.py --run    # move files
python organize_downloads.py --undo   # undo the last run

find_duplicates.py

finds exact copies by comparing file contents (SHA-256), not names, and moves the extra copies into a Duplicates folder.

python find_duplicates.py             # preview
python find_duplicates.py --run       # move duplicates
python find_duplicates.py --undo      # put them back

downloads_report.py

shows where the space went, and moves installers older than 30 days into a Review folder.

python downloads_report.py            # report only
python downloads_report.py --run      # move old installers
python downloads_report.py --undo     # put them back
